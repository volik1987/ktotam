# Кто там — macOS (ade_ktotam.app)

Узнаёт, кто сидит перед ноутбуком, и говорит голосом «Привет, Имя!» / «Пока, Имя!».

## Как пользоваться
1. «Люди» → ввести имя → «Добавить».
2. Под камерой: «Серия снимков» → выбрать человека → «Снять 20 кадров» (покрутить головой).
3. Дальше обучение поправками: у лица в кадре кнопки «Да, Вася» / «Нет, это… → Маша / Новый человек».
   Вкладка «Проверка» — лента «что думала программа», там же подтверждать или поправлять.
4. Порог узнавания и задержка «пока» — во вкладке «Настройки».

## Как устроено
- `Camera.swift` — AVFoundation, 1280×720; `--fake-camera <папка>` подаёт фото вместо камеры.
- `FaceEngine.swift` — Vision: поиск лица и точек, выравнивание по зрачкам в кроп 160×160,
  вектор признаков `VNGenerateImageFeaturePrintRequest` (L2 = 1).
- `Brain.swift` — узнавание ближайшими соседями (среднее 3 ближайших снимков человека, порог + отрыв),
  трекер лиц между кадрами с голосованием по 8 кадрам, присутствие (привет/пока).
- `Store.swift` — SQLite `~/Library/Application Support/Ktotam/faces.sqlite`: users + samples (вектор + JPEG кропа;
  при смене `FaceEngine.version` векторы пересчитываются из кропов).
- Поправка закрепляет имя за лицом, пока оно в кадре, и добирает ещё 6 снимков к правильному человеку.

## Сборка и тесты
```
./build.sh                                   # → ~/Applications/ade_ktotam.app
build/Ktotam --selftest [папка человек/ролик/кадры]   # логика, база, точность
build/Ktotam --import <папка Имя/фото> [--db файл]    # добавить фото в базу
build/Ktotam --db t.sqlite --fake-camera <папка> --mute --test-fix Имя --snapshot out.png 8
```
Точность на 13 людях из стоковых видеозвонков (426×240): обучение на одном ролике, проверка на другом —
98% по кадру, 100% с голосованием трека. Порог 0.42: чужого за своего принимает ~8% кадров.
